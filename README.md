# 离线飞书式项目看板（进阶版）

基于 16 字段 Excel 模板，用脚本生成一个**自包含离线 HTML 看板**，在本地实现飞书仪表盘类似的五类功能：

- **指标卡**：8 张（总任务数、已完成、进行中、待评审、阻塞、拖期数、里程碑完成率、本周到期）
- **切片器**：7 组（阶段、负责人、协作部门、状态、风险等级、拖期状态、关键路径），多选并联动全部组件
- **透视表**：行/列/值维度可切换，默认「阶段 × 状态 × 任务计数」
- **项目统计柱状图**：各阶段任务数、各阶段平均进度、负责人待办负载（内联 SVG，无外部依赖）
- **甘特图**：按阶段分组、里程碑、拖期/预警配色、今日线、**日/周/月缩放**、**关键路径标记**
- **关键路径与浮动时差**：由「前置任务」自动做 CPM 推算，无需额外填表
- **搜索与可分享视图**：搜索框联动全部组件；筛选状态写进 URL，可收藏、可发给别人

## 快速开始

1. 用 Excel/WPS 打开 `家电产品项目_任务数据.xlsx`，在「任务」页维护任务（每行一个叶子任务）；
2. 双击 `运行看板.command`，脚本会自动校验数据并生成、打开 `项目看板.html`；
3. 看板为只读展示，**Excel 是唯一数据源**：改完保存后重新运行一次即可刷新。

也可以在终端手动执行：

```bash
python3 build_dashboard.py --input 家电产品项目_任务数据.xlsx --output 项目看板.html
```

> 看板打开时按**系统当天日期**自动计算拖期/预警，无需每天重新生成；
> 需要回归测试时可在浏览器地址栏加参数：`项目看板.html?today=2026-08-20`。

## 本地操作台（可选）

不想记命令行时，可以用网页式操作台完成同一套“选 Excel → 校验/分析 → 生成看板”：

- 源码直接运行：`python3 看板操作台.py`（自动打开浏览器，仅监听 `127.0.0.1`，完全离线）；
- 页面操作：选择 Excel → 生成并分析 → 打开看板 / 下载 HTML → 环境自检 → 退出；
- 生成结果自动保存到 `~/项目看板操作台/项目看板.html`；上传的 Excel 副本用完即删；
- **单实例**：已经开着一个时再双击，只会把浏览器指向那一个，不会起第二个服务；
- **不留后台进程**：页面每 30 秒心跳一次，关掉标签后闲置 10 分钟自动退出
  （`--idle-timeout 0` 可关掉这个行为）；
- 一键发布：双击 `打包Mac应用.command`，它会**构建 → 冻结包自检 → 同步 `交付物/`
  → 重打源码快照 → 打印校验和**，任一步失败即中止；
- 产物**仅支持 Apple 芯片（M 系列）Mac**，Intel Mac 无法运行；
- 打包时会排除 `ssl` / `_hashlib` / `lzma` / `bz2` 等用不上的模块——这个全离线、
  只跑 127.0.0.1 明文 HTTP 的应用不需要 OpenSSL，能省下约 4MB 的 `libcrypto` + `libssl`；
  排除清单由 `tests/test_console.py::PackagingExcludesTest` 实跑验证，用上了就会先红；
- 分发给最终用户的一页说明见 `使用说明.md`。

## 甘特图操作

- 右上角可切换**日 / 周 / 月**三档时间粒度；切换后视口保持在原来的日期附近；
- 搜索框匹配 任务ID / 任务 / 子任务 / 负责人 / 交付物 / 备注，与切片器叠加生效；
- 筛选条件、搜索词、时间粒度、透视维度、选中任务都会写进地址栏 `#`，**可收藏或直接把链接发给别人**；
- 关键路径任务加深红描边并标「关键」，非关键任务在副行显示浮动天数；
- 左侧「任务清单」列横向滚动时**冻结**，时间刻度表头纵向滚动时**冻结**；
- 打开看板自动把视口定位到**今天**；筛选或展开任务详情后滚动位置保持不变；
- 时间刻度随粒度变化：日视图为「周 / 日」两行（周行按整周合并、日行逐日、每月 1 号显示「N月」、周末带底色），周视图为「月 / 周」，月视图为「年 / 月」；
- 点任务名或色条展开详情；里程碑跨多天时显示一条浅色区间条，菱形锚定在计划结束当天。

## 数据字段

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| 任务ID | 是 | 全局唯一，如 T001，供前置任务引用 |
| 阶段 | 是 | 阶段分组与统计维度 |
| 任务 / 子任务 | 任务必填 | 任务名；子任务留空表示任务本身 |
| 负责人 | 是 | 可多人，用顿号或逗号分隔 |
| 协作部门 | 否 | 统计与切片维度 |
| 计划开始 / 计划结束 | 是 | 日期，格式 yyyy-mm-dd |
| 进度% | 是 | 0～100 |
| 前置任务 | 否 | 依赖的任务ID，多个用英文逗号分隔 |
| 里程碑 | 否 | 是/否 |
| 优先级 | 否 | 高/中/低 |
| 状态 | 否 | 未开始/进行中/待评审/已完成/阻塞 |
| 风险等级 | 否 | 高/中/低 |
| 交付物 / 备注 | 否 | 补充信息 |

「项目配置」页可修改项目名称、项目起止日期、预警提前天数（默认 5）、工作日。

## 状态与配色规则

| 计算状态 | 颜色 | 规则 |
| --- | --- | --- |
| 已完成 | 绿 | 进度 = 100% |
| 拖期 | 红 | 计划结束早于今天，且进度 < 100% |
| 预警 | 黄 | 距计划结束 ≤ 预警天数，且进度 < 80% |
| 阻塞 | 紫 | 状态 = 阻塞 |
| 待评审 | 橙 | 状态 = 待评审 |
| 进行中 | 蓝 | 进度 > 0 且无异常 |
| 未开始 | 灰 | 其余 |

## 关键路径口径

- 无前置的任务以其**计划开始**为最早开始；`ES = max(前置 EF) + 1`，`EF = ES + 工期 - 1`；
- 自最晚 EF 逆推 `LS / LF`，总浮动时差 `TF = LS - ES`，`TF = 0` 即关键路径；
- **按日历日计算**。「项目配置」页的「工作日」字段目前只作展示，不参与任何推算。

## 校验规则

生成前脚本会检查：必填项、日期格式与先后顺序、进度范围、枚举值、任务ID 唯一、
前置任务存在、**依赖无环**、项目起止日期合法。**所有错误一次性列出**，不用修一个跑一次；
出错时定位到具体行，且不会留下半成品文件。

此外还有一层**提示（warning）**，不阻塞出图，会显示在看板顶栏的「数据提示」里：

- 值不在「选项字典」页的候选中（写错字会静默多出一个切片器分类）
- 状态与进度矛盾（状态=已完成但进度<100，或反之）
- 任务日期落在项目起止范围之外
- 依赖倒挂；与前置任务搭接（汇总成一条）

加 `--strict` 可把提示一并当作错误处理。

## 输入护栏

| 护栏 | 默认上限 | 可调参数 |
| --- | --- | --- |
| 时间轴跨度 | 1095 天（3 年） | `--max-span-days` |
| 任务行数 | 800 行 | `--max-rows` |

一个年份手误（把 2026 打成 2226）会撑出 7 万天的时间轴、14 万个 DOM 节点直接卡死浏览器，
护栏会拦下来并指出是哪一行的哪个日期撑开的。

「进度%」「计划开始」等列若填的是 Excel 公式，脚本会取 Excel 的计算结果缓存；
只有当公式从未被 Excel 算过（无缓存值）时才报错，并提示先用 Excel/WPS 打开保存一次。

## 开发与自检

双击 `运行自检.command`，或：

```bash
python3 -m unittest discover -s tests -t tests -v
```

只依赖标准库；装了 playwright 会额外跑浏览器回归（几何对齐、响应式、交互联动），
没装则自动跳过。前端源码在 `assets/`，改完跑一次 `python3 build_dashboard.py --dev`
就能直接打开 `assets/template.html` 边改边看。

`tests/test_perf.py` 是性能基准，默认只做宽松的回归护栏；加 `KANBAN_PERF_TARGET=1`
会改用验收线（2000 行 × 5 年下首屏 ≤ 2s、切片器重绘 ≤ 200ms、HTML ≤ 3MB），
优化没落地之前它就该是红的。

## 与飞书的差异

- 本地看板是只读快照，飞书支持在线协作、评论与自动提醒；
- 「已完成」本地按进度=100% 判定；飞书公式字段按「状态 = 已完成」判定；
- 本地看板不依赖网络，文件可复制给他人直接打开；
- 同一份模板可同时用于本地看板和飞书导入（导入步骤见 `飞书协作/导入回流操作手册.md`）。
